# Дашборд ZZap для Grafana

[zzap-integration.json](zzap-integration.json) — компактный дашборд из 6 панелей
для Grafana 12/13. Встроенные Stat и State timeline, без сторонних плагинов.
Период — 6 часов, обновление — 15 секунд, часовой пояс — UTC.

## Импорт

1. Откройте **Dashboards → New → Import** и загрузите JSON.
2. Выберите существующий источник **Prometheus** и нажмите **Import**.
3. Проверьте **Prometheus**, **Job** и **Instance** вверху дашборда.
   По умолчанию выбраны `chatwoot-zzap` и `zzap.gt-shop.ru:443`.

Для обновления уже импортированного дашборда используйте тот же UID
`zzap-integration-health` и подтвердите замену при импорте.

Если метрики ещё не собираются, настройте
[scrape `/metrics` с Bearer token](../monitoring.md#prometheus).
Токен хранится в Prometheus; Grafana обращается к Prometheus datasource.

## Панели

| Панель | Что показывает |
|---|---|
| Метрики доступны | Получает ли Prometheus метрики сервиса (`up`). |
| Polling ZZap | Есть ли деградация входящего polling. Порог задаётся в worker. |
| Worker | Свежий ли heartbeat: не старше 120 секунд. |
| Ошибок подряд | Последовательные HTTP и сетевые ошибки polling. |
| HTTP ZZap | Последний HTTP-код polling, включая 403 и 429. |
| История состояния | Доступность метрик, polling и heartbeat за выбранный период. |

При неудачном scrape текущие значения exporter скрываются, чтобы старые
samples не показывали здоровое состояние. Отсутствие истории или метрик —
**«Нет данных»**. До инициализации polling и первого heartbeat их статус
также отсутствует. Пропуски на истории не соединяются.

«Нет деградации» означает, что порог без успешного polling ещё не превышен.
Свежий heartbeat показывает активность worker. HTTP 200 не гарантирует
корректный прикладной ответ; HTTP 0 означает отсутствие ответа или истории.

Настройка exporter и alerts: [документация мониторинга](../monitoring.md).
